## Overview

Numbers adds a fully configurable side panel to RimWorld's colonist management UI, displaying any tracked pawn statistic as a sortable column — needs, skill levels, health conditions, mood, work capacity stats, and more. Color-coded thresholds provide at-a-glance status awareness, and all statistics added by other mods are automatically surfaced.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Numbers** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Configurable Columns** | Add, remove, and reorder any pawn statistic as a table column |
| **Column Sorting** | Click any column header to sort the entire colonist list by that value |
| **Color Coding** | Threshold-based red/yellow/green coloring for quick status identification |
| **Mod Statistics** | Automatically surfaces statistics added by other installed RimWorld mods |
